# Novara Fashion E-commerce Sales Analysis

## Project Overview

This project focuses on analyzing Novara Fashion's 2022 e-commerce sales data using Microsoft Excel. The objective is to identify sales trends, understand customer purchasing behavior, evaluate sales channel performance, and generate actionable business insights through an interactive dashboard.

## Objectives

- Analyze overall sales performance and order trends.
- Identify top-performing sales channels.
- Understand customer demographics and purchasing patterns.
- Evaluate clothing category performance.
- Analyze regional sales distribution.
- Identify business opportunities through data-driven insights.

## Tools & Technologies

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- Data Visualization
- Business Analysis

## Dashboard Features

- Sales performance KPIs
- Monthly sales trend analysis
- Sales by e-commerce channel
- State-wise sales analysis
- Customer gender and age group analysis
- Clothing category performance
- Order status analysis
- Interactive filtering

## Key Business Insights

The analysis explores:

- Monthly sales patterns and seasonal trends.
- Sales contribution across e-commerce platforms.
- Customer segments contributing to sales.
- Best-performing clothing categories.
- Regional sales performance.
- Order fulfillment and return patterns.

Detailed findings and actionable recommendations are documented in the Business Insights Report.

## Project Files

- `Novara Fashion Sales Analysis.xlsx` – Excel workbook containing the analysis and interactive dashboard.
- `Novara Fashion Business Insights Report.word` – Detailed report covering findings, business implications, and recommendations.
- `Dashboard.png` – Dashboard preview.

## Business Recommendations

- Focus on high-performing sales channels.
- Optimize inventory for popular clothing categories.
- Improve customer targeting using demographic insights.
- Investigate seasonal sales fluctuations.
- Monitor returns, cancellations, and fulfillment performance.

## Conclusion

This project demonstrates the application of Microsoft Excel for e-commerce sales analysis, interactive dashboard creation, and business insight generation. It showcases the ability to transform raw sales data into meaningful information that supports data-driven decision-making.
